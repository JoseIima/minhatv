# Minha TV

Projeto front-end puro para streaming via Google Drive.

## Capas

- `armji.jpg`

## Recursos

- Temporadas em abas
- Voltar do player para a temporada correta
- Continuar assistindo com localStorage
- Favoritos
- Próximo episódio
- Marcar como visto
- Navegação por setas/Enter para TV
- Banner estilo Netflix
